## Fast path

1. Read sections 3–6 of the brief for the design system.
2. Open Google Stitch and paste the **Master Style Prompt** from the prompt pack.
3. Generate screens in the order listed in section 10.2 of the brief.
4. Export to Figma and rebuild with the variables and components in section 11.
5. Wire the flows in section 9.
